# Закрывающий тег

Проектная работа по вёрстке: страница из восьми карточек с вариативным шрифтом, фиксированным градиентным фоном, CSS-фильтрами, анимированным сердцем-лайком, модальным окном `dialog` и адаптивом под 375px.

Ссылка на репозиторий: https://github.com/Habiba394/zakrivayuschiy-teg-ad

Ссылка на опубликованный сайт: https://habiba394.github.io/zakrivayuschiy-teg-ad/

## Структура

- `index.html` — разметка
- `fonts/` — Inter (вариативный) и Press Start 2P, подключение в `fonts.css`
- `styles/` — `variables.css`, `globals.css`, `style.css`, `animations.css`
- `scripts/` — `like.js` (лайки), `dialog.js` (открытие модального окна)
- `svg/sprite.svg` — иконка дискеты (`symbol` + `use`)
- `images/` — картинки карточек, фавиконки, иконка для iOS
